📜 Hard Business Rules (Backend Enforced)

Rule 1: Session Ownership Boundary

Customer ID is derived strictly from the authenticated token/session. Agent parameters specifying arbitrary customer IDs are rejected with 403 Forbidden.

Rule 2: 14-Day Delivery Return Window

Delivered orders can only be refunded if (fixed_clock - delivery_date) <= 14 days. Checked against deterministic scenario clock.

Rule 3: Cancelled Order Full Refund

Orders cancelled before fulfillment are always eligible for 100% refund, provided no prior refund exists.

Rule 4: Database Uniqueness & Idempotency

Database enforces UNIQUE(order_id, scenario_run_id) and UNIQUE(operation_key, scenario_run_id) to guarantee zero double refunds even in concurrent conditions.
